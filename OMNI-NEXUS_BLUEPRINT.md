## 2. THE NEURAL UI & UX (Frontend Constraints)
The UI must deliver visual violence and extreme immersion. 
- **Typography & Minimalism:** English-first. Eradicate all unnecessary borders, boxes, and loud colors. Rely entirely on massive, high-contrast typography (e.g., 'Playfair Display' for giant H1s, 'Inter' for highly readable body text) and extreme negative space.
- **Bionic Reading Protocol:** To force rapid reading and dopamine looping, a client-side (or build-time) script MUST be applied to all `<p>` tags within articles, wrapping the first half of every word (over 3 letters) in `<b>` tags or `font-weight: 800`.
- **Dopamine Micro-Interactions:** Cards and links must feature fluid, subliminal animations (e.g., scale up slightly, change contrast) on hover to lower the psychological barrier to clicking.

The system operates as a multi-agent swarm, not a single linear prompt.
1. **Director Agent:** Scans for micro-trends. Selects high-ROI seed topics and defines the psychological "hook/angle".
2. **Writer Agent:** Uses Neuro-Linguistic Programming (NLP) techniques. MUST output Markdown. MUST include: a polarizing hook, a Markdown Table (Comparison), Pros/Cons, and an open-ended FAQ.
3. **Editor Agent:** Scans the context and seamlessly injects monetization links (NordVPN, Amazon, SaaS) ONLY where it solves a reader's specific pain point.
4. **THE META-CRITIC AGENT (The Founder's Proxy) [CRITICAL]:**

   - **Adversarial Loop:** Before any deployment, the Meta-Critic asks: "Is this article profound? Does this UI trap the user?" If NO, it forces a regeneration with stricter constraints. It constantly suggests improvements and architectural mutations.
